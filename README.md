<summary><b>🚀 SpaceshipLab — Desafio Técnico LabTIME (Padrões de Projeto)</b></summary>
<br>
Simulador em console das mecânicas de uma nave espacial, desenvolvido para o desafio técnico de estágio em desenvolvimento de jogos da LabTIME. Implementa três Padrões de Projeto (Observer, State e Decorator) para resolver restrições arquiteturais reais: contingência do núcleo, troca dinâmica de função da tripulação e empilhamento de modificadores de armas. README documenta a justificativa de cada padrão escolhido e o papel de cada classe.
