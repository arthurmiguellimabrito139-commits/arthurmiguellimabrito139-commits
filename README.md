<summary><b>🧳 App-Viagem — Sistema de Gestão de Viagem em Grupo</b></summary>
<br>
Aplicação full stack completa para controlar passageiros e pagamentos de uma viagem em grupo. <summary><b>🚀 SpaceshipLab — Desafio Técnico LabTIME (Padrões de Projeto)</b></summary>
<br>
Simulador em console das mecânicas de uma nave espacial, desenvolvido para o desafio técnico de estágio em desenvolvimento de jogos da LabTIME. Implementa três Padrões de Projeto (Observer, State e Decorator) para resolver restrições arquiteturais reais: contingência do núcleo, troca dinâmica de função da tripulação e empilhamento de modificadores de armas. README documenta a justificativa de cada padrão escolhido e o papel de cada classe.

<summary><b>🛒 AquiCompraAquiPaga — Loja de Jogos (Java + Spring Boot)</b></summary>
<br>
Backend de e-commerce acadêmico para venda de jogos digitais — cadastro de clientes, carrinho, cálculo de total e registro de compras. Construído em Java com Spring Boot e banco H2, aplicando POO na prática: classes e objetos bem definidos, encapsulamento e polimorfismo (cada forma de pagamento sobrescreve seu próprio comportamento).
